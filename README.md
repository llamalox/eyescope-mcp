# Eyescope MCP

Public package for the Eyescope local MCP server. Cursor, Codex, and Claude use it to search and rough-cut an Eyescope library.

The Mac app icon is `icon.png`. Release `v0.1.2` also contains `eyescope.mcpb`, the installable bundle.

- Icon: https://github.com/llamalox/eyescope-mcp/releases/download/v0.1.2/icon.png
- Product: https://eyescope.io
